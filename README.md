# Pixel Dungeons RPG

Un juego de mazmorras en estilo pixel art desarrollado en .NET con MonoGame y una pequeña motor propio.

## Características
- Exploración de mazmorras en vista superior
- Movimiento y combate básicos
- Motor de juego modular con `PixelEngine`
- Base para expansión de contenido, enemigos, inventario y niveles

## Tecnologías
- C#
- .NET 9
- MonoGame
- PixelEngine

## Ejecución
1. Abre la solución en Visual Studio o VS Code.
2. Restaura paquetes NuGet.
3. Ejecuta el proyecto `PixelDungeons`.
